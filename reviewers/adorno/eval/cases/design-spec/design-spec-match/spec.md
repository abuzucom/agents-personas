# Button component spec

Primary action button.

## States
- default: background `color-action-primary`, label `color-on-primary`
- hover: background `state-hover`
- focus: 2px `color-focus-ring` outline, visible
- disabled: background `color-action-disabled`, `cursor: not-allowed`
